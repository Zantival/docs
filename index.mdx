FusaShop es una plataforma de comercio electrónico construida con **Laravel 12** que soporta tres roles de usuario: consumidores, comerciantes (MiPymes) y analistas. Este manual cubre todo lo que un desarrollador necesita para instalar, configurar, extender e integrar la plataforma.

## Primeros Pasos

<Steps>
  <Step title="Revisa los requisitos">
    Asegúrate de tener PHP 8.2+, MySQL/PostgreSQL y Node.js. Consulta [Requisitos del Sistema](/instalacion/requisitos).
  </Step>
  <Step title="Instala el proyecto">
    Clona el repositorio, instala dependencias y configura el entorno. Sigue la guía de [Instalación Local](/instalacion/instalacion-local).
  </Step>
  <Step title="Configura las variables de entorno">
    Ajusta credenciales de base de datos, correo y pasarela de pagos en el archivo `.env`. Ver [Variables de Entorno](/instalacion/variables-de-entorno).
  </Step>
  <Step title="Explora los módulos">
    Familiarízate con los módulos de [Autenticación](/modulos/autenticacion), [Comerciantes](/modulos/comerciantes) y la [API REST](/api/autenticacion-api).
  </Step>
</Steps>

## Arquitectura en un vistazo

FusaShop sigue el patrón MVC de Laravel con controladores organizados por rol. La API REST utiliza Laravel Sanctum para autenticación basada en tokens. Los pagos se procesan a través de PayU y el módulo de análisis se apoya en scripts Python que el backend ejecuta mediante `symfony/process`.
